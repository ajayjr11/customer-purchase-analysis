# Customer Purchase Analysis

## 📊 Project Overview

This project analyzes customer purchasing behavior to identify patterns and insights related to products, purchases, discounts, shipping methods, subscriptions, and customer segments.

The project demonstrates practical **Data Analyst skills** including data exploration, SQL querying, aggregation, segmentation, and business-focused analysis.

## 🎯 Objectives

* Analyze customer purchasing behavior
* Identify top-performing products
* Analyze product ratings
* Compare shipping methods
* Analyze discount usage
* Segment customers based on previous purchases
* Analyze subscription status
* Identify patterns in customer purchasing activity

## 🛠️ Tools & Technologies

* **MySQL** – Data querying and analysis
* **SQL** – Data aggregation, filtering, grouping, CTEs, and window functions
* **Excel** – Data exploration and basic analysis
* **Power BI** – Data visualization and dashboard creation
* **Python / Pandas** – Data cleaning and exploratory analysis

## 📁 Dataset
